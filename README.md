# Nez AI

An intelligent local AI assistant built using Java, Spring Boot, React, Ollama and modern open-weight LLMs.

## Vision

Nez AI is a modular AI platform designed to run primarily offline while supporting coding assistance, reasoning, image understanding, memory, plugins and voice.

## Tech Stack

- Java 21
- Spring Boot
- React
- TypeScript
- PostgreSQL
- Ollama
- Docker
